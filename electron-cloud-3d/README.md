# 电子云 · 3D 轨道演示（Three.js）

类氢原子（Z = 1）**30 个原子轨道（1s → 4f）**概率密度 |ψ|² 的三维可视化，用于课堂教学演示。
单个 HTML 文件、完全离线、双击即可打开——不需要服务器、不依赖网络。

![轨道](https://img.shields.io/badge/轨道-30%20个-blue) ![Three.js](https://img.shields.io/badge/Three.js-r187-blue) ![离线](https://img.shields.io/badge/离线-单文件-green)

## 快速开始

| 方式 | 操作 |
| --- | --- |
| **直接打开（推荐）** | 双击 `电子云3D演示.html`（文件 ~2.2 MB，已内联 Three.js，无需网络） |
| 本地服务器 | `python -m http.server 8000` 后访问 `http://localhost:8000/电子云3D演示.html` |

支持 Chrome / Edge / Firefox / Safari 等现代浏览器，支持触屏。

## 功能

**电子云渲染**
- 每个点是一次「测量」记录到的电子位置；点的疏密 = 概率密度 |ψ|²（点密 ≠ 电子多）
- 22 万 / 12 万 / 5 万三档粒子数；辉光 / 柔和 / X 射线透视三种渲染模式
- 三种配色：**相位（ψ 正负，暖/冷色）**、**|ψ| 幅值（等离子色带）**、**轨道类型（s/p/d/f）**
- 切换轨道时粒子带错落地飞向新位置（按半径壳层配对），首次进入从朦胧球壳汇聚成轨道

**90% 概率面（轨道边界面）**
- 一键开关（或按 `B`）：把「电子出现概率 90% 的区域」圈成曲面——即通常所说的原子轨道形状
- 真实等值面：阈值 ρ 由 ∫_{|ψ|²>ρ}|ψ|²dV = 0.9 精确求出（可分离分解 + 二分），曲面用 marching tetrahedra 提取，菲涅尔玻璃壳着色
- 2s 呈现**内外两个壳层**（中间隔着径向节面），3d_z² 带腰部圆环，4f 呈八瓣——结构与教科书一致

**教学信息**
- 每个轨道的量子数（n、l、m）、能量 Eₙ = −13.6/n² eV、径向/角向节面数、亚层容量
- 节面三维可视化：径向节面（球面）+ 角向节面（平面/锥面），可开关
- 径向分布函数 D(r) = r²|R|² 曲线图（标注峰值、⟨r⟩、径向节面、90% 半径）
- 坐标轴、极坐标网格、原子核（尺寸随轨道尺度缩放）

**全视角与导出**
- 拖动 / 单指旋转，滚轮 / 双指缩放，双击复位；等轴 / 侧视 / 俯视预设视角
- 电子云缓慢自转；「录制」按钮导出 **12 秒环绕视频**（WebM / MP4，自动下载），可直接插入 PPT

**流畅模式**
- 一键开启（或粒子数选「流畅 · 6 万」）：6 万粒子 + 关闭光晕层 + 限制渲染分辨率（DPR ≤ 1.25）+ 略小粒子，帧率优先；退出后自动恢复原设置
- 底部工具条有实时 FPS 读数（低于 30 变琥珀色）；帧率持续偏低时也会自动降档（仅一次）

**快捷键**：`←` `→` 切换轨道 · `空格` 自转 · `1``2``3` 配色 · `N` 节面 · `B` 概率面 · `A` 坐标轴 · `R` 复位 · `F` 全屏 · `H` 隐藏界面 · `?` 帮助

## 物理说明

波函数取 Z = 1 类氢解析解：

```
ψ_{nlm}(r,θ,φ) = R_{nl}(r) · Y_l^m(θ,φ)
```

- 径向部分 R：关联拉盖尔多项式，长度单位 a₀（玻尔半径）
- 角向部分 Y：**实球谐函数**（化学中的 p_x / d_xy / f_xyz 等轨道），归一化系数由数值积分精确求出（不查表硬编码，避免文献常数笔误）
- 粒子抽样：半径 ~ r²|R|²dr（1D 逆 CDF），方向 ~ |Y|²dΩ（2D 逆 CDF），两个边缘分布独立合成 |ψ|² 的正确分布
- 颜色表示波函数**相位**（决定成键），不是电荷；s 轨道（n ≥ 2）的相位会在径向节面处翻转
- 多电子原子中轨道形状与此相似、半径略有不同；能级仅取决于 n 是类氢结果

物理核心经过 **757 项自动化测试**（`node tests/test_physics.mjs` 609 项 + `node tests/test_boundary.mjs` 148 项）：

- 波函数：与合流超几何（Sakurai 记法）交叉验证、归一化 ∫r²R²dr = 1、同 l 正交性、实球谐归一化与正交性、已知解析式
- 采样：30 个轨道的平均半径 / 方向直方图 / 相位占比 vs 理论、节面个数与几何零点
- 90% 概率面：阈值包住 90% 概率（蒙特卡洛）、等值面顶点落在阈值上（中位偏差 < 8%）、1s 表面 = r90 球面、2s 双壳层、2pz 沿轴拉长、3dxy 节面上无顶点

## 目录结构

```
electron-cloud-3d/
├── 电子云3D演示.html      ← 交付物：单文件离线演示（双击打开）
├── src/
│   ├── template.html      # 页面骨架（构建时内联）
│   ├── style.css          # 深色玻璃质感 UI
│   ├── physics.js         # 物理核心（波函数 / 实球谐 / 采样 / 节面 / 90% 概率面）
│   └── app.js             # Three.js 场景、着色器、形变过渡、UI、录制
├── tests/
│   ├── test_physics.mjs   # 波函数与采样测试（609 项）
│   └── test_boundary.mjs  # 90% 概率面测试（148 项）
├── tools/build_single.py  # 构建脚本：把 three.js 与 src/* 内联成单文件
└── node_modules/three/    # 仅构建时需要（产物已完全自包含）
```

## 重新构建

```bash
npm install                        # 首次：拉取 three.js（仅构建用）
python tools/build_single.py       # 构建单文件
node tests/test_physics.mjs        # 波函数与采样测试（609 项）
node tests/test_boundary.mjs       # 概率面测试（148 项）
```

## 已知说明

- 软渲染 / 老旧显卡上可能自动降低粒子数（帧率保护，仅自动降级一次）
- 录制功能依赖浏览器 MediaRecorder（Chrome / Edge / Firefox 均支持；Safari 需 14.1+）
- 页面暴露了 `window.__snap()`（截取 canvas PNG）与 `window.__app`（状态/调试接口），便于二次开发
